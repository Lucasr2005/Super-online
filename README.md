# 🛒 Super-online: Tu Supermercado en Línea

Super-online es una aplicación web de comercio electrónico que permite a los usuarios navegar por productos, agregarlos al carrito, registrarse, iniciar sesión y realizar compras pagando con Mercado Pago. La aplicación está dividida en un frontend construido con React y un backend construido con Node.js y Express.

## Características

### Frontend

- **Navegación de Productos:** Vea productos por categoría con filtros y ordenamiento.
- **Carrito de Compras:** Agregue y elimine productos de su carrito.
- **Autenticación de Usuarios:** Regístrese e inicie sesión en su cuenta.
- **Proceso de Pago:** Realice pedidos y pague utilizando Mercado Pago.
- **Historial de Pedidos:** Vea todos los pedidos realizados por su cuenta.
- **Diseño Responsivo:** Interfaz de usuario compatible con dispositivos móviles.

### Backend

- **API RESTful:** Endpoints para gestionar productos, categorías, usuarios y pedidos.
- **Autenticación y Autorización:** Basada en tokens JWT para proteger las rutas.
- **Integración de Pagos:** Integración con Mercado Pago para procesar pagos.
- **Base de Datos PostgreSQL:** Utiliza una base de datos PostgreSQL para almacenar los datos de la aplicación.
